## Why

当前打牌、抓牌、响应窗口和动画回执已经具备服务端权威状态机、公开事件和动画屏障的基础，但响应窗口的生命周期仍主要依赖 `pendingActions`、`playerActions`、`responseSummary` 等状态片段组合表达，客户端需要从快照中推断按钮可见性、出现牌是否应保留以及动画何时接管。随着多人并发响应、动画 ACK、断线恢复和本地按钮反馈叠加，这种隐式协议容易造成响应按钮残留、过早消失、出现牌重复动画、无人响应归位时机不一致等问题。

本变更将整体牌局流程收敛为“服务端权威事务 + 公开动画事件流 + 显式响应窗口协议”。目标是在不推翻现有动画系统和服务端引擎的前提下，让出牌、抓牌、无人响应、多人响应和响应完成动画都由明确的协议驱动，降低客户端推断复杂度，并让后续优化有稳定边界。

## What Changes

- 将“出牌”和“抓牌”统一建模为出现牌流程：服务端发布 `draw` / `discard` 公开事件，并通过 `appearanceResolution` 明确选择 `await-response` 或 `auto-discard` 分支。
- 明确 `await-response` 出现牌事件的职责：所有客户端播放出现动画并保留出现牌；动画回执完成后，服务端才开放对应响应窗口。
- 明确 `auto-discard` 出现牌事件的职责：所有客户端播放出现动画并直接归位到最终弃牌槽；归位动画完成后，服务端继续下一次摸牌或后续推进。
- 引入显式响应窗口协议字段，包含窗口 id、来源、候选席位、等待席位、已决策席位、当前最佳选择摘要、仍能影响裁决的阻塞席位、窗口关闭原因等公共摘要。
- 通过私密通道仅向仍可操作的本人下发响应按钮；当高优先级或更靠前响应顺序的选择已经无法被本人推翻时，本人的响应按钮必须收起且后续提交被拒绝。
- 明确响应窗口的 UI 生命周期：按钮弹出/消失属于本地 UI 过渡，不建立公开动画屏障；最终无人响应、吃、碰、招、踏、胡等桌面共享结果仍必须生成公开事件并等待动画回执。
- 明确服务端裁决语义：响应窗口内任一合法选择成为当前最佳选择后，服务端只等待仍可能击败该选择的未决候选；若不存在阻塞候选，立即裁决并关闭窗口。
- 明确所有玩家均过牌或托管过牌后的归位流程：服务端发布 `unclaimed` 公开事件，将保留出现牌移入弃牌区；每个单独过牌选择不得生成公开动作事件。
- 收敛客户端职责：客户端只消费服务端公开事件播放桌面动画，只根据响应窗口私密动作渲染本人按钮，不再根据本地规则或零散状态补造响应流程。
- 强化断线、重连、增量与快照恢复规则：重连客户端必须以当前公开事件、响应窗口摘要和本人私密动作恢复显示；不得补播已不需要回执的旧响应窗口 UI。

## Capabilities

### New Capabilities

无。本变更是在现有在线牌局、实时同步和客户端动画能力上补强协议契约，不引入独立的新产品能力。

### Modified Capabilities

- `server-game-engine`: 明确出现牌事务、响应窗口协议字段、提前裁决条件、窗口关闭结果和公开事件生成顺序。
- `realtime-state-sync`: 明确公共响应窗口摘要、每连接私密响应动作、增量/快照下发、动画等待与响应 UI 的并行关系。
- `client-animation-system`: 明确客户端只按权威公开事件和私密响应动作驱动动画/UI，响应按钮弹出/收起不阻塞公开动画，出现牌保留与释放由事件协议控制。

## Impact

- 服务端引擎：`services/backend/src/game/core/engine.js` 需要补全响应窗口摘要、阻塞席位计算、私密动作过滤、窗口关闭原因和公开事件衔接。
- 房间与 socket 服务：`services/backend/src/game/room.js`、`services/backend/src/socket-server.js` 需要在快照和 delta 中稳定下发公共响应窗口摘要与每连接私密动作。
- 客户端在线控制器：`js/net/online.js` 需要优先使用服务端协议字段构建本地状态，减少 `pendingActions` / `playerActions` 推断和补造逻辑。
- 客户端动画控制器：`js/game/animation/controller.js`、`js/game/animation/state-controller.js`、`js/game/animation/presets.js` 需要让出现牌、无人响应归位、响应完成和按钮 UI 的职责更清晰。
- 渲染与布局：`js/game/renderer.js`、`js/game/layout.js` 需要支持响应窗口私密动作的稳定弹出/收起、等待态和失效态。
- 回归测试：需要覆盖服务端响应窗口裁决、socket 私密动作下发、出现牌分支、动画回执顺序、断线重连恢复和按钮可见性。
