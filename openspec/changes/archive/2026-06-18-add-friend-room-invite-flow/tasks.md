## 1. 服务端等待房间能力

- [x] 1.1 扩展房间玩家模型，创建和加入等待房间时保存 `ready`、`online`、`lastSeenAt` 等等待房间状态
- [x] 1.2 增加等待房间公开快照构建函数，返回房间号、房主、局数、玩家列表、准备状态和 `canStart`
- [x] 1.3 增加 `roomInfo` action，允许房间内玩家获取等待房间公开状态
- [x] 1.4 扩展 `joinRoom`，支持分享参数入房时返回等待房间公开状态，并处理房间不存在、已满、已开局、已结束
- [x] 1.5 在加入房间前检查玩家是否已有其他未结束房间，避免一个玩家同时占用两张未结束牌桌
- [x] 1.6 增加 `setReady` action，幂等设置当前玩家准备状态并返回最新等待房间状态
- [x] 1.7 调整开局 action，校验房主、等待状态、至少 2 名真人、房主已准备后才开局，空座继续由 AI 补位
