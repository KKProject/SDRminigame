## ADDED Requirements

### Requirement: 事件类型化动画屏障
服务端权威状态机 SHALL 根据公开事件类型、响应窗口状态和玩家在线状态计算动画屏障的必需回执名单。响应关键事件 MUST 保证需要操作的在线玩家能看到并处理当前牌；非关键观赏或收尾事件 MUST NOT 因离线玩家长期阻塞牌局推进。

#### Scenario: 等待响应事件要求相关在线玩家
- **WHEN** 服务端发布 `appearanceResolution=await-response` 的 `draw` 或 `discard` 事件
- **THEN** 服务端 MUST 将仍在线且可能需要响应或需要观察当前牌的必要玩家加入回执名单
- **AND** 服务端 MUST 在入场动画回执满足后开放或继续响应窗口

#### Scenario: 非关键事件不等待离线玩家
- **WHEN** 服务端发布 `pass`、`settlement`、普通收尾或其他非关键观赏事件
- **AND** 某玩家已经被标记为离线或连接不存在
- **THEN** 服务端 MUST NOT 将该玩家加入当前事件的必需回执名单
- **AND** 该事件 MUST 能在剩余必要条件满足后继续推进

#### Scenario: 结果事件保留在线玩家观看
- **WHEN** 服务端发布 `hu`、`circle-loss` 或 `draw-round` 结果类事件
- **THEN** 服务端 MUST 对仍在线的牌桌玩家建立必要动画屏障
- **AND** 离线玩家 MUST NOT 阻塞该结果事件进入结算状态

### Requirement: 当前屏障离线玩家快速移除
服务端 SHALL 在心跳、socket 断开、订阅恢复和动画 ACK 处理过程中刷新当前动画屏障的在线玩家集合。当前屏障中的玩家被确认离线或超时时，服务端 MUST 将其从必需回执名单移除，并在剩余条件满足时继续推进。

#### Scenario: 等待动画期间玩家断线
- **WHEN** 当前公开事件正在等待动画回执且某个必需玩家 socket 断开或心跳超时
- **THEN** 服务端 MUST 标记该玩家离线并从当前必需回执名单移除
- **AND** 若剩余必需玩家均已回执，服务端 MUST 继续当前事件的后续推进

#### Scenario: 离线移除不改变规则裁决
- **WHEN** 玩家因离线从动画屏障回执名单移除
- **THEN** 服务端 MUST 只改变动画等待条件
- **AND** 服务端 MUST NOT 因该移除直接改变已完成的规则裁决、手牌或分数

#### Scenario: 离线玩家重连后重新纳入新事件
- **WHEN** 离线玩家重新连接并恢复为在线状态
- **THEN** 服务端 MAY 在后续新事件中按在线状态重新计算其是否需要回执
- **AND** 服务端 MUST NOT 要求其补交已经推进完成的旧事件回执

### Requirement: 非关键动画自动推进边界
服务端权威状态机 SHALL 对没有在线必需观看者的公开事件自动推进。若连续多个公开事件均无必需回执方，服务端 MAY 连续推进到下一个响应窗口、手动决策点或结果落态，但 MUST 保持事件序号和权威状态一致。

#### Scenario: 无在线观看者事件自动跳过
- **WHEN** 当前公开事件没有任何必需回执玩家
- **THEN** 服务端 MUST 自动解除该动画屏障并执行事件的 pending continuation
- **AND** 服务端 MUST 继续同步最新权威状态

#### Scenario: 推进到响应窗口停止
- **WHEN** 自动跳过若干非关键动画后进入真人可响应窗口
- **THEN** 服务端 MUST 停止在该响应窗口等待合法响应、过牌或托管
- **AND** 服务端 MUST 向在线可响应玩家下发当前响应窗口状态和私密动作

#### Scenario: 推进到结果落态
- **WHEN** 自动跳过无必需观看者事件后牌局进入 `phase=result`
- **THEN** 服务端 MUST 在持久化前同步房间生命周期状态
- **AND** 后续客户端重连 MUST 看到一致的结果状态

### Requirement: 动画屏障诊断
服务端 SHALL 为动画屏障输出可排查的脱敏诊断信息，包括事件类型、事件序号、必需席位、已回执席位、离线移除、超时推进和自动跳过原因。诊断 MUST NOT 输出 OPENID、token、密钥、MongoDB URI 或玩家私密手牌。

#### Scenario: 非关键事件被跳过可追踪
- **WHEN** 服务端因没有必需回执方或离线玩家移除而跳过某个动画屏障
- **THEN** 服务端日志 MUST 记录事件序号、事件类型和跳过原因
- **AND** 日志 MUST 使用席位或计数表达玩家信息，不得输出敏感身份凭证

#### Scenario: 动画屏障卡住可定位
- **WHEN** 当前房间长时间等待动画回执
- **THEN** 服务端诊断 MUST 能显示仍在等待的席位、已回执席位和截止时间
- **AND** 诊断 MUST 能区分等待在线玩家、玩家离线移除和超时托管推进
