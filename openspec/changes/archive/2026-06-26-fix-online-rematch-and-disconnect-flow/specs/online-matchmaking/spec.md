## MODIFIED Requirements

### Requirement: 牌桌生命周期与座位管理
系统 SHALL 由服务端维护牌桌的生命周期状态（等待、进行中、结算、最终结果、关闭）与座位归属。系统 MUST 保证一名玩家在同一牌桌只占用一个座位；牌桌最终结果状态 MUST 允许同桌玩家查看结果、退出或按规则同意重开；牌桌关闭后 MUST 释放其占用的匹配/座位资源。

#### Scenario: 满座开局
- **WHEN** 牌桌座位全部就位且满足开局条件
- **THEN** 服务端 MUST 将牌桌状态置为进行中并触发开局
- **AND** 各客户端 MUST 收到开局后的初始权威状态

#### Scenario: 牌局结束后关闭
- **WHEN** 一局结束且无人继续或玩家主动退出导致房间无人保留
- **THEN** 服务端 MUST 将牌桌置为关闭状态
- **AND** 服务端 MUST 释放该牌桌相关的座位与匹配资源

#### Scenario: 最终结果留在牌桌
- **WHEN** 牌桌完成配置的最大局数
- **THEN** 服务端 MUST 将牌桌置为最终结果状态
- **AND** 同桌玩家 MUST 仍能重连并查看最终结果、退出或参与重开确认

### Requirement: 查询玩家未结束牌桌
系统 SHALL 允许已登录玩家通过自有 HTTPS 游戏 API 查询自己是否参与了未结束牌桌。服务端 MUST 以访问 token 解析出的 `OPENID` 为身份来源，并 MUST 只返回该玩家所在且尚未关闭的牌桌信息；最终结果状态在玩家退出前仍属于未结束牌桌。

#### Scenario: 返回未结束牌桌
- **WHEN** 已登录玩家参与的牌桌仍处于等待、进行中、本局结算后可继续或最终结果状态
- **THEN** 服务端 MUST 返回该牌桌的 `roomId`、玩家座位、牌桌状态、版本和牌桌配置
- **AND** 客户端 MUST 能使用返回信息继续执行等待房恢复或 socket 重连流程

#### Scenario: 没有未结束牌桌
- **WHEN** 当前玩家没有参与任何未结束牌桌
- **THEN** 服务端 MUST 返回没有牌桌的结果
- **AND** 服务端 MUST NOT 创建新牌桌

#### Scenario: 已关闭牌桌不返回
- **WHEN** 当前玩家只参与了已关闭牌桌
- **THEN** 服务端 MUST 返回没有未结束牌桌

### Requirement: 最大局数结束牌桌
系统 SHALL 在牌桌达到创建时配置的最大局数后进入最终结果状态。达到最大局数后，服务端 MUST 阻止直接继续下一局；客户端 MUST 展示牌局已经结束，并允许玩家退出，且允许房主发起当前房间重开确认。

#### Scenario: 达到最大局数后结束
- **WHEN** 牌桌完成第 `settings.maxRounds` 局结算
- **THEN** 服务端 MUST 将牌桌标记为最终结果状态
- **AND** 客户端 MUST 展示当前结果和牌局已经结束提示

#### Scenario: 未达到最大局数可继续
- **WHEN** 牌桌完成一局结算且当前局数小于 `settings.maxRounds`
- **THEN** 服务端 MUST 允许房主继续开启下一局

#### Scenario: 最终结算房间仍可重连
- **WHEN** 玩家重新登录且存在自己尚未退出的最大局数结束牌桌
- **THEN** 服务端查询未结束牌桌 MUST 返回该牌桌
- **AND** 客户端 MUST 恢复到最终结果牌桌视图

### Requirement: 最大局数后当前房间重开
系统 SHALL 支持最大局数结束后由房主发起当前房间重开。房主发起后，所有仍在房间内的真人玩家 MUST 同意；全部同意后服务端 MUST 在当前房间清零已打局数并开启新一局。

#### Scenario: 房主发起重开
- **WHEN** 牌桌处于最终结果状态且房主点击再来一局
- **THEN** 服务端 MUST 记录房主已发起并已同意重开
- **AND** 客户端 MUST 向其他真人玩家展示等待同意状态

#### Scenario: 全员同意后重开
- **WHEN** 房间内所有真人玩家均已同意重开
- **THEN** 服务端 MUST 清零当前房间已打局数并开启新一局
- **AND** 房间号、座位和房主 MUST 保持不变

#### Scenario: 玩家退出最终结果房间
- **WHEN** 玩家在最终结果状态点击退出
- **THEN** 服务端 MUST 将该玩家从房间占用中释放
- **AND** 客户端 MUST 返回在线大厅
