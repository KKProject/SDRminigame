# 云数据库安全规则配置

在线牌局把完整手牌保存在 `rooms`，只把公开信息写入 `roomStates`。为避免客户端绕过云函数读取其他玩家手牌，需要在微信云开发控制台配置以下集合权限。

## 集合权限

| 集合 | 客户端读取 | 客户端写入 | 说明 |
| --- | --- | --- | --- |
| `users` | 禁止 | 禁止 | 仅允许 `login` 云函数维护玩家资料 |
| `rooms` | 禁止 | 禁止 | 包含完整权威状态和所有玩家手牌，只允许 `game` 云函数访问 |
| `matchQueue` | 禁止 | 禁止 | 匹配状态只通过 `game` 云函数查询和修改 |
| `roomStates` | 允许读取 | 禁止 | 只包含公共牌桌状态，客户端通过 `watch` 监听 |

## 控制台操作

1. 打开微信开发者工具中的「云开发」。
2. 进入「数据库」，确认存在 `users`、`rooms`、`matchQueue`、`roomStates` 四个集合。
3. 分别打开集合的「权限设置」。
4. `users`、`rooms`、`matchQueue` 设置为「仅云函数可读写」。
5. `roomStates` 设置为「所有用户可读，仅云函数可写」。
6. 用开发者工具验证 `roomStates.watch()` 能收到更新，同时客户端直接读取 `rooms` 会被拒绝。

## 验证标准

- 在线牌局可以正常登录、开局和同步。
- 客户端直接调用 `wx.cloud.database().collection('rooms').doc(roomId).get()` 必须失败。
- 客户端直接写入 `roomStates` 必须失败。
- `game` 云函数的 `pull` 动作只能返回调用者本人的手牌。
